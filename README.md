# LomFon · ลมฝน

แผนที่อากาศแบบเว็บแอป (แนว Windy + RainViewer) เปิดผ่านลิงก์ได้ทันที ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องใช้ API key

A static weather-map web app in the spirit of Windy and RainViewer. No server, no API keys — deploys straight to GitHub Pages.

## ฟีเจอร์ / Features

- test
- **ลมเคลื่อนไหว** (particle animation) บนแผนที่ทั่วโลก
- **ชั้นข้อมูลสี**: ลม, ลมกระโชก, อุณหภูมิ, ฝน (พยากรณ์), เมฆ, ความชื้น, ความกดอากาศ
- **ไทม์ไลน์รายชั่วโมง 5 วัน** พร้อมปุ่มเล่นภาพเคลื่อนไหว
- **เรดาร์ฝนสด** ย้อนหลังราว 2 ชม. เล่นเป็นภาพเคลื่อนไหว (RainViewer)
- **ภาพดาวเทียมรายวัน** (NASA GIBS)
- **เลือกแบบจำลอง**: Auto, ECMWF, GFS, ICON, JMA, GEM, Météo-France, UK Met Office
- **เลือกพื้นที่โฟกัส** (เช่น ไทย, อาเซียน, ญี่ปุ่น ฯลฯ) เพื่อให้ชั้นข้อมูลละเอียดขึ้น
- **แตะจุดใดก็ได้** ดู: สภาพปัจจุบัน, ฝน 2 ชม. ข้างหน้า (ทุก 15 นาที), AQI/PM2.5, คลื่นทะเล, กราฟรายชั่วโมง 48 ชม., พยากรณ์ 16 วัน, **เทียบ 6 โมเดล**
- ค้นหาสถานที่, ตำแหน่งของฉัน, ที่โปรด, แชร์ลิงก์ (ลิงก์จำมุมมอง ชั้นข้อมูล และจุดที่เลือก)
- ไทย/อังกฤษ, เปลี่ยนหน่วย °C/°F และ km/h, m/s, kt, mph
- ติดตั้งลงหน้าจอโฮมได้ (PWA)

## เปิดใช้บน GitHub Pages

1. Push โค้ดนี้ขึ้น repo (ไฟล์อยู่ที่ root)
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)`** แล้ว Save
3. รอ 1–2 นาที จะได้ลิงก์ `https://<username>.github.io/lomfon/`

> หมายเหตุ: GitHub Pages ของ repo **private** ต้องใช้แพ็กเกจ GitHub Pro ขึ้นไป ถ้าใช้บัญชีฟรีให้ตั้ง repo เป็น public ก่อนเปิด Pages

## รันในเครื่อง / Run locally

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (ES modules ใช้กับ `file://` ไม่ได้):

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## โครงสร้าง / Structure

```
index.html            หน้าแอป
css/style.css         สไตล์ (ธีมมืด, รองรับมือถือ)
js/app.js             ตัวควบคุมหลัก: แผนที่, ไทม์ไลน์, ค้นหา, แชร์, ตั้งค่า
js/config.js          แหล่งข้อมูล, ชั้นข้อมูล, สเกลสี, รายชื่อประเทศ
js/grid.js            ดึงกริดพยากรณ์ (Open-Meteo multi-location) + interpolation
js/layers.js          ชั้น canvas: heatmap สี และอนุภาคลม
js/radar.js           เรดาร์ RainViewer
js/panel.js           แผงพยากรณ์ของจุดที่เลือก
js/i18n.js            ข้อความไทย/อังกฤษ
js/util.js            หน่วย, การจัดรูปแบบ, สเกลสี, storage
sw.js                 service worker (PWA)
```

## แหล่งข้อมูลและข้อจำกัด / Data & limits

| ข้อมูล | แหล่ง | ข้อจำกัดของรุ่นฟรี |
|---|---|---|
| พยากรณ์, ชั้นข้อมูลแผนที่, AQI, คลื่น | [Open-Meteo](https://open-meteo.com/) (CC BY 4.0) | ใช้ฟรีสำหรับงานไม่เชิงพาณิชย์ มีโควตาเรียกต่อนาที/วัน — ถ้าใช้เชิงพาณิชย์ต้องซื้อ API key |
| เรดาร์ฝน | [RainViewer](https://www.rainviewer.com/api.html) | ย้อนหลังราว 2 ชม., ทุก 10 นาที, ซูมสูงสุดระดับ 7, สีแบบเดียว, ไม่มีพยากรณ์เรดาร์ |
| ภาพดาวเทียม | [NASA GIBS](https://earthdata.nasa.gov/gibs) | ภาพรายวัน (ของเมื่อวาน) ไม่ใช่ภาพสด |
| แผนที่ฐาน | © OpenStreetMap, © CARTO | — |

ชั้นข้อมูลสีบนแผนที่สร้างจาก "กริดจุดพยากรณ์" ราว 160–220 จุดต่อครั้ง แล้ว interpolate จึงละเอียดน้อยกว่า Windy เมื่อมองทั้งโลก แต่ละเอียดขึ้นเมื่อซูมเข้าหรือเลือกพื้นที่โฟกัส

### ไอเดียพัฒนาต่อ
- GitHub Action ดึงข้อมูล GFS (GRIB2) ทุก 6 ชม. แปลงเป็น JSON แล้วเก็บไว้ใน Pages → ได้ชั้นข้อมูลทั้งโลกความละเอียดสูงแบบ Windy โดยไม่ต้องมีเซิร์ฟเวอร์
- ชั้นข้อมูลคลื่นทะเลบนแผนที่, ภาพดาวเทียมอินฟราเรดแบบใกล้เวลาจริง
